# Yaqoob Ali Portfolio

A responsive personal portfolio for Yaqoob Ali, built with plain HTML, CSS and JavaScript.

## Features
- Editorial, spacious visual design
- Day / Night theme switch with localStorage persistence
- Responsive layout for desktop, tablet and mobile
- Subtle hover transitions without heavy animation
- Profile image included in `assets/profile.jpg`
- No framework or build step required

## Run locally
Open `index.html` in a browser.

## Publish free
The site can be deployed directly to GitHub Pages, Netlify or Vercel.
